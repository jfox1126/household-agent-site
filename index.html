household-agent

A private calendar assistant for one household.

household-agent is a small personal program that reads its owner's Google Calendar and sends a short daily preview and a weekly summary to a private chat shared by the two adults in one household.

It is not a product. It is not offered to anyone else, there is no sign-up, and it has no users beyond the two people it was written for.

What it does

  • Reads calendar events for the week ahead.
  • Sends a plain-text summary — titles, times and dates only — to a private chat.
  • Points out gaps, such as a night with no childcare arranged.

What it will and will not do

  • It creates a calendar event only when one of the two adults presses a button to confirm it, never on its own.
  • It removes an event only if it created that event and a person presses a button to undo it. It never changes or removes any other event.
  • It never adds guests to an event, so it never sends an invitation.
  • The only text it sends to Anthropic, which provides its language model, is text a person has deliberately sent it. It does not send calendar events or email to Anthropic.
  • It may read its owner's own email, to count it and to read replies to the questions it sent. It cannot change or delete email.
  • It sends email to one address only, a personal assistant service its owner chose. It sends the questions it cannot answer itself, and shows the reply in the chat.
  • Beyond that, it shares nothing with anybody outside the household except Telegram and Apple, which carry the chat, and Google, which holds the calendar and the email.

It runs on a single personal computer, and it keeps its credentials in files that only the program and its owner can read. If it stops running, a small watcher on Google's servers emails its owner. The watcher receives no calendar or message content.
