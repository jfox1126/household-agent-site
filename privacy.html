Privacy policy

household-agent · last updated 17 September 2026

household-agent is a private program used by the two adults of a single household. It is not offered to the public and has no other users. This policy describes what it reads, where that goes, and how to stop it.

What it accesses

With the account holder's consent, household-agent reads Google Calendar events using the calendar.events.readonly scope. That permission is read-only: the program cannot create, change or delete any event, and it requests no other Google permission.

From each event it uses the title, the start and end times, whether the event lasts all day, whether it is marked busy or free, and whether invitees have replied. It does not use event descriptions, locations or conference links.

Where the information goes

  • Calendar information is processed on one personal computer and written to a database on that computer.
  • Summaries are sent to a private chat readable only by the two adults in the household.
  • Nothing is sold, published, used for advertising, or shared with anyone outside the household.
  • A future version will send limited event text to Anthropic, which provides the language model used to phrase summaries. Both adults will be told before that happens, and neither the current version nor any version sends calendar information to any other third party.

How long it is kept

Calendar information is kept only as long as it is needed for the current and upcoming week, and records of what the program has sent are kept so it does not repeat itself. Deleting the program's database removes everything it holds.

Credentials

The access credential is stored in a file on the computer that only the program's own restricted account can read. It is never displayed, logged or transmitted anywhere except to Google when requesting calendar data.

Withdrawing access

The account holder can revoke household-agent's access at any time, with immediate effect, from the Google Account permissions page at myaccount.google.com/permissions. No request to us is needed. Once revoked, the program can no longer read anything.
