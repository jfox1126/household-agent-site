Privacy policy

household-agent · last updated 2 October 2026

household-agent is a private program used by the two adults of a single household. It is not offered to the public and has no other users. This policy describes what it reads, what it may create, where information goes, and how to stop it.

What it accesses

With the account holder's consent, household-agent may hold two Google Calendar permissions: calendar.events.readonly, which lets it read events, and calendar.events, which also lets it create, change and delete them. For its owner's own Gmail accounts, and no one else's, it may also hold gmail.readonly, which lets it read email but not send, change or delete any. It requests no other Google permission.

It creates an event only when one of the two adults presses a button to confirm it, never on its own, and only on the one calendar it is set up to use. It deletes an event only if it created that event and a person presses a button to undo it. It never changes or deletes any other event, and it never adds guests, so it never sends an invitation.

From each event it reads, it uses the title, the start and end times, whether the event lasts all day, whether it is marked busy or free, and whether invitees have replied. It does not use event descriptions, locations or conference links.

Today it uses email only to count it: how many messages arrived in a week, of what kind, and how many are still waiting on a reply. No email, sender, subject or text is stored, shown in a chat, or sent to anyone. Before it uses email for anything more, this page will say what, and the change will be dated.

Where the information goes

  • The program runs on one personal computer, and its database is on that computer.
  • Summaries and replies are sent through Telegram to chats readable only by the two adults in the household.
  • Text a person deliberately sends it goes to Anthropic, which provides the language model that reads it. Calendar events and email are not sent to Anthropic.
  • An event it creates is stored by Google on the calendar, like any other event.
  • Nothing is sold, published or used for advertising, and nothing is shared with anyone else.

How long it is kept

Calendar events are read when they are needed and are not stored; the program keeps a record of what it has sent so it does not repeat itself. Email is read when it is counted and is not stored. Text a person sends it may be kept on the computer, with a record of what was done with it, until its owner deletes it. Deleting the program's database removes everything it has recorded. Events it has created stay on the calendar, like any other event, until someone deletes them.

Credentials

Its credentials are stored in files on the computer that only the program and its owner can read. Each is sent only to the service that issued it, and none is displayed or logged.

Withdrawing access

The account holder can revoke household-agent's access at any time, with immediate effect, from the Google Account permissions page at myaccount.google.com/permissions. No request to us is needed. Once revoked, the program can no longer read or change the calendar, or read the email.

household-agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Either adult can stop it sending anything by sending /stop in the chat.
